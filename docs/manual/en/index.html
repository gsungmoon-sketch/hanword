hanword User Manual

1. Overview

hanword is a browser-based word processor for Korean. A document is a single self-contained standard HTML file (images are embedded as data URIs), and editing and shortcuts follow Hangul (HWP) conventions. It opens and saves HWPX, DOCX, HTML and plain text, and a command-line tool (hanword) built on the same core converts and checks files without a browser.

  • The core needs only the Python 3.10+ standard library. No extra packages are required.
  • By default it runs in local mode, reachable only from your own machine (127.0.0.1). A stateless public converter mode (WP_PUBLIC=1) exists for hosting on the internet.
  • Repository: github.com/gsungmoon-sketch/hanword · Licence: MIT.
ModeWhere documents liveUse
Local (default)Documents folder on the server machineYour own PC or a small trusted LAN
Public converter (WP_PUBLIC=1)Nowhere (browser upload/download only)Internet, behind an HTTPS reverse proxy

2. Installation

2.1 Downloading and verifying SHA256

Pick the file for your system from the GitHub release.

FileFor
hanword-<ver>-windows-x64-setup.exeWindows 64-bit installer
hanword-<ver>-macos-arm64.pkgmacOS (Apple silicon)
hanword-<ver>-macos-x64.pkgmacOS (Intel)
hanword-<ver>-linux-x64.tar.gzLinux x86-64 (systemd)
hanword-<ver>.pyzAny OS (needs Python 3.10+)
SHA256SUMSChecksums of the files above

Verify that the download is intact.

# Linux (file and SHA256SUMS in the same folder)
sha256sum -c SHA256SUMS --ignore-missing
# macOS
shasum -a 256 hanword-0.1.6-macos-arm64.pkg
# Windows (PowerShell or Command Prompt)
Get-FileHash .\hanword-0.1.6-windows-x64-setup.exe -Algorithm SHA256
certutil -hashfile hanword-0.1.6-windows-x64-setup.exe SHA256

The printed value must equal the matching line in SHA256SUMS.

2.2 Windows

  1. Run setup.exe (administrator rights required).
  2. The binary is unsigned, so SmartScreen may block it: click More info → Run anyway.
  3. Installed to C:\Program Files\hanword\. A Windows service named hanword (WinSW) is registered and starts automatically on 127.0.0.1:8088.
  4. Documents are stored in %ProgramData%\hanword\documents.
  5. Choose hanword 열기 (open hanword) in the Start menu to open the browser.
  6. Uninstall from Settings → Apps. Your data is kept unless you choose to remove it (silent uninstall: /PURGEDATA also deletes data).

2.3 macOS

  1. Open the pkg. It may be unsigned or not notarised; if blocked, right-click the pkg and choose Open, or allow it in System Settings › Privacy & Security.
  2. Installs /usr/local/hanword, the command /usr/local/bin/hanword and the LaunchDaemon com.hanword.server (starts automatically).
  3. Data: /Library/Application Support/hanword · Logs: /Library/Logs/hanword.
  4. Uninstall: sudo /usr/local/hanword/uninstall.sh [--purge] (--purge also deletes data).

2.4 Linux (systemd)

tar xzf hanword-0.1.6-linux-x64.tar.gz
cd hanword-0.1.6-linux-x64
sudo ./install.sh [--port N]
  • Installs to /opt/hanword, command /usr/local/bin/hanword, data /var/lib/hanword (user hanword), unit hanword.service.
  • Status: systemctl status hanword · Logs: journalctl -u hanword
  • Uninstall: sudo /opt/hanword/uninstall.sh [--purge]

2.5 Any OS: .pyz or source

# single file (.pyz)
python hanword-0.1.6.pyz serve

# from a source checkout
git clone https://github.com/gsungmoon-sketch/hanword
cd hanword
python server.py --host 127.0.0.1 --port 8088 --data ~/hanword-documents
python hanword convert in.docx out.hwpx   # CLI

Packaged installs provide one command, hanword: hanword serve [--host] [--port] [--data], hanword --version, plus every CLI subcommand. From source, the server is server.py and the CLI is the hanword script.

3. First run

  1. Packaged installs: the service is already running. Open http://127.0.0.1:8088/ in a browser (on Windows use the Start menu entry). From source or .pyz, start the server first.
  2. A blank document appears; just type. The top has the menus (파일 File, 편집 Edit, 보기 View, 입력 Insert, 서식 Format, 쪽 Page, 도구 Tools) and a toolbar.
  3. Press Alt+S to save; the document is stored as name.html in the documents folder.
  4. For other formats use the File menu: “Save as Hangul document (HWPX)”, “Save PDF”, and so on.
NoteUse 127.0.0.1 or localhost in the address bar. Any other host name gives a 421 error (see chapter 7). If the port is taken, change it with --port.

4. Using the editor

The UI is in Korean; menu names are given below with an English gloss. Menus shown are for local mode. In public converter mode the File menu offers “Open from my PC (upload)” and “Download as …” (HTML, HWPX, DOCX, TXT, PDF), and nothing is stored on the server. Shortcuts follow Hangul conventions.

Keys written with a comma, such as Ctrl+N,T, are two-step: press Ctrl+N, release, then press T. Menus may differ slightly between versions.

4.2 Characters and paragraphs

Set character formatting from the toolbar or the character dialog (Alt+L): font, size, text colour, shading colour, bold, italic, underline, strikethrough, superscript (Alt+Shift+P) and subscript (Alt+Shift+S). The paragraph dialog (Alt+T) sets alignment and indentation. Headings (h1 to h3) and lists (bullet or numbered, up to 9 levels) are set with Styles (F6) and List properties.

4.3 Tables

Create a table from the Insert menu. Inside a cell press F5 to start a cell block, extend it with the arrow keys, then merge, split, or change borders and background in one step.

ActionKeys
Cell blockF5 then arrows
Merge / splitwith a block: M / S
Borders / backgroundwith a block: L / C

A table can be placed as inline (like a character), paragraph (wrap), or fixed. Wrap switches left/right automatically as you drag and text flows around the table. A table can also be split vertically (표−) or joined (표+).

4.4 Pictures and shapes

  • Pictures (Insert → Picture): each is one object block. Resize width and height independently with the corner and edge handles, crop any of the four sides, rotate or flip, wrap text around it, and add a caption (number plus description). Pictures are embedded in the document.
  • Shapes: open the shape menu (도형▾) in the toolbar and pick rectangle, ellipse or line. Drag the two end handles of a line to make horizontal, vertical or diagonal lines (angles snap). Change fill, line colour, thickness and solid/dashed/dotted; group, align and distribute objects; set stacking order (front/back).

4.5 Media and page background

  • Insert → Media (video/audio) puts a playable video in the document. Click the video to play or pause; the control bar sets position and volume. In public converter mode the chosen file is kept only inside your browser. In local mode, insertable media lives in the media/ folder of the documents folder.
  • Page background colour: choose a swatch in Page setup to colour every page.
  • Using a picture as the page background is still planned (the menu item is marked “계획중”, in planning).

4.6 Page setup, headers/footers, table of contents, endnotes

  • Page setup (F7): paper size, orientation, margins, background colour.
  • Header/Footer and Page numbers: Page menu. Page break: Ctrl+Enter.
  • Generate table of contents: Page menu. Builds a contents list at the very start of page 1 based on current page numbers. Afterwards it is ordinary text you can edit; regenerate it after the content changes (it does not update by itself).
  • Endnotes and caption numbers renumber automatically when you add or delete them. Use “Renumber endnotes” or “Renumber captions” if needed.

4.7 Find/replace, spell check, word count

Ctrl+F (F2) find, Ctrl+L find next, Ctrl+H replace. F8 spell check; Tools → Word count.

4.8 Undo and edit history

Undo is lossless: after undoing and editing again the earlier branch is not lost, and repeated undo walks back through discarded branches too. With Tools → Set/change edit-history password the history is encrypted and stored with the document when you save (requires cryptography; off by default). Enter the password when reopening to keep undoing across sessions. The password is stored nowhere; if lost, only the history is unrecoverable (the document text is unaffected).

4.9 Printing and PDF

  • Save PDF (Alt+P) and Print now (browser) use the browser print dialog, or build a raster PDF inside the browser. No extra components needed.
  • Vector PDF (selectable, searchable text) needs the server-side node + playwright setup (section 2.6).
  • Printing directly to a printer through a dedicated device is not part of this public edition. Use browser printing.

4.10 Saving and opening other formats

  • Save as TXT: tables are drawn with box characters so they keep their shape in Notepad or a terminal; headings are underlined, lists use bullets, and pictures/videos/shapes appear as [그림]/[영상]/[도형]. Page breaks remain as form-feed characters and are restored when the TXT is reopened.
  • Open TXT: UTF-8 or CP949 is detected automatically; text becomes paragraphs.
  • Open PDF: “as is” (pages rendered as pictures: not editable, layout preserved) or “text only” (text extracted into paragraphs: editable, layout lost). A scanned PDF with no text is refused in “text only”; use “as is”.

5. File formats and limits

FormatOpenSaveNotes
HTML (.html)yesyesNative format, images embedded
HWPX (.hwpx)yesyesOWPML (KS X 6101), handled with the standard library
DOCX (.docx)yesyes
TXT (.txt)yesyesUTF-8/CP949 detection

DOC (.doc)text onlynoNo formatting
PDF (.pdf)text or page imagesyespoppler-utils needed for import

Known limits

  • Complex HWPX objects (such as charts), tracked changes and macros are not supported.
  • .doc gives text only; .hwp needs pyhwp; HWP 3.x cannot be opened.
  • PDF import yields either text or page images.

Size and concurrency limits

  • CLI input: at most 200 MB. Server POST body: at most 64 MB.
  • PDF rasterising: at most 300 pages.
  • Concurrent conversions: WP_CONV_MAX (default 2); beyond that the server answers HTTP 503 (retry shortly).

Round-trip check

To see whether converting through another format loses content, run hanword roundtrip FILE --via hwpx|docx|html (exit code 1 on loss).

7. Troubleshooting

8. Security

Local mode has no loginAnyone who can reach the port can read, write and delete documents. Therefore it binds to 127.0.0.1 by default, and any other address is refused unless WP_PUBLIC=1 or WP_ALLOW_REMOTE=1 is set. Use WP_ALLOW_REMOTE=1 only on a trusted LAN.
  • Host header check against DNS rebinding (421 on mismatch); cross-origin POST blocked (403).
  • CSP with a per-request nonce, X-Frame-Options DENY, nosniff, no-referrer.
  • Upload size limits; zip-bomb and XXE-safe parsing of HWPX/DOCX (expat, entity checks); link-scheme whitelist.
  • WP_DEBUG=1 opens a local debug bridge. Never enable it on a shared machine.

Exposing it to the internet

Run with WP_PUBLIC=1 (stateless converter mode), put it behind an HTTPS reverse proxy, and set WP_PUBLIC_HOST to your domain. Never expose local mode directly.

# hanword in public mode on 127.0.0.1
WP_PUBLIC=1 WP_PUBLIC_HOST=docs.example.com WP_SITE_URL=https://docs.example.com hanword serve --port 8088

# Caddy
docs.example.com {
    reverse_proxy 127.0.0.1:8088
}

# nginx (inside a server block; TLS certificates configured separately)
location / {
    proxy_pass http://127.0.0.1:8088;
    proxy_set_header Host $host;
    client_max_body_size 64m;
}

Report vulnerabilities through GitHub Security Advisories (see SECURITY.md in the repository).

apply: edit operations

A position is [block index, character offset] (0-based). Operations run in order; if any fails the whole call fails (naming the operation) and the input is untouched. Text inside locked blocks (tables, pictures, page breaks) is not edited by plain positions; for text inside a table cell, the text operations (insert_text, delete_range, set_style, split_paragraph) also accept a cell position [table block, row, col, cell paragraph, offset] (row/col = grid coordinates, a merged cell is addressed by its top-left; start and end must be in the same cell). Table operations use grid coordinates too; structural operations first fill the missing slots of short rows with empty cells, and refuse tables whose spans overlap.

opArguments
insert_textpos, text
delete_rangestart, end (start < end)
set_stylestart, end, attrs: bold/italic/underline/strike/sup/sub (true; sup and sub exclude each other), color/highlight (#RRGGBB), size (1-400), font, link. A value of null or false removes it
set_block_typeindex, type (p/h1/h2/h3/li/div); optional list (bullet|number), level (li only), align, indent
split_paragraphpos
merge_paragraphindex (merges that block with the next)
insert_pgbreakpos
delete_blockindex
insert_blockindex, block
insert_tablepos, rows (1-200), cols (1-64); splits the paragraph at pos
table_insert_rows / table_delete_rowsindex, at, n (insert n ≤ 100). A row inserted inside a merged cell grows its rowspan; deleting rows shrinks spans (a merged cell whose first row is deleted keeps its text); deleting the last row is refused (use delete_block)
table_insert_cols / table_delete_colsindex, at, n — same rules with colspan. When cells have widths, a new column gets the average width of its neighbours and the table width is kept (columns rescaled)
table_mergeindex, r0, c0, r1, c1 (grid, inclusive). Rectangles only: a merged cell crossing the edge is refused. Text = paragraphs of the non-empty cells in row order; format = first cell

Fonts

Bundled fonts (SIL OFL 1.1, unmodified upstream files): NanumGothic, NanumMyeongjo (TTF), Noto Sans KR (OTF), Pretendard (woff2). Noto Serif KR, D2Coding, Hamchorom Batang/Dotum (Hancom) and UnBatang (GPL) are not bundled; without them the editor falls back to bundled fonts. To add them, download from the official sources (the Hancom Hamchorom download page; the Un fonts package, e.g. fonts-unfonts-core), convert to woff2, and place them in the font folder (app/font or WP_FONTDIR) with these names:
