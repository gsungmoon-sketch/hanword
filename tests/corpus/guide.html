1. 글자와 문단, 표

글자 모양은 도구모음과 글자 모양 대화상자에서 정합니다. 글자색, 음영색, 크기, 진하게·기울임·밑줄, 그리고 위첨자·아래첨자까지 지원합니다.

2. 그림 삽입과 편집

그림은 입력 메뉴에서 넣습니다. 넣은 그림은 한 개의 개체 블록이 되어 다음을 할 수 있습니다.

  • 가로·세로를 각각 따로 크기 조절(모서리·변 손잡이)
  • 자르기(crop) — 네 변을 잘라 원하는 부분만
  • 회전·반전, 그리고 어울림 배치(글이 그림을 피해 흐름)
  • 그림 아래 캡션으로 번호와 설명

4. 문서 관리와 저장

한워드는 문서 구조도 알아서 관리합니다.

  • 목차 생성 — 쪽 메뉴 → 목차 생성으로 현재 쪽번호 기준 목차를 1페이지 맨 앞에 만듭니다. 생성 후엔 일반 텍스트라 자유롭게 고칠 수 있고, 내용이 바뀌면 다시 생성하세요(자동 갱신 없음).
  • 미주·캡션 번호 — 넣고 지워도 번호가 자동으로 다시 매겨집니다1)
  • 무손실 되돌리기 — 되돌린 뒤 새로 편집해도 이전 흐름이 사라지지 않습니다. 되돌리기를 계속 누르면 버렸던 가지까지 전부 거슬러 올라갑니다.
  • 편집 역사 보존(암호) — 저장할 때 암호를 설정하면 되돌리기 역사가 암호로 잠긴 채 문서와 함께 보존됩니다. 다시 열 때 암호를 넣으면 지난 세션의 역사까지 이어서 되돌릴 수 있습니다. 도구 메뉴 편집 역사 암호 설정/변경에서 켜며, 설정하지 않으면 꺼져 있습니다. 암호는 어디에도 저장되지 않아 분실 시 역사만 복구 불가(문서 본문은 무관).

가장 큰 장점은 저장입니다. 문서는 네이티브 HTML로 저장되어 어디서나 열리고, 필요하면 PDF와 HWPX(한글 문서)로도 내보냅니다.

5. 미디어와 쪽 배경 — 문서를 넘어

한워드 문서는 글·표·그림을 넘어 미디어까지 담습니다. 전부 표준 HTML이라 문서 하나로 완결됩니다.

  • 영상·소리 삽입 — 입력 메뉴 미디어 삽입(영상·소리)으로 문서 안에 재생되는 영상을 넣습니다. 영상 몸통을 클릭하면 재생/일시정지, 아래 컨트롤바로 구간·음량을 조절합니다. 선택 시 나타나는 💾 단추로 파일 이름 확인·변경·교체, 크기는 오른쪽 아래 손잡이, 배치는 [배치]로 조절합니다. 기기와 웹에서 모두 삽입할 수 있습니다(웹판은 고른 파일을 이 브라우저 안에 저장).
  • 쪽 배경색 — 편집 용지에서 색상 견본으로 모든 페이지에 배경색을 입힙니다.
  • 페이지 배경 그림 — 그림을 넣고 선택한 뒤 개체 도구 [배경]으로 모든 쪽 배경으로 지정합니다(한글 저장엔 미포함). 수식(과학) 등은 준비 중.

동영상은 가벼운 브라우저 지원을 위해 안내문에서 제외했습니다.

▲ 샘플 사진과 동영상 — 동영상 몸통을 클릭하면 바로 재생됩니다.

문서이면서 미디어까지 — 열려 있고 자유로운 작성 도구.


6. 정보 보호 — 내 문서는 내 브라우저 안에

한워드는 가입도, 서버 저장도 없습니다. 작성·편집·저장(내 기기로 내려받기)·열기(올리기)·자동 복구 초안은 모두 내 브라우저 안에서 처리되며, 서버엔 누구의 문서도 저장되지 않습니다. PDF·한글(HWPX)로 내보내거나 한글 파일을 열 때만 변환을 위해 내용이 서버로 잠시 전송되고, 변환 직후 폐기되어 저장되지 않습니다.

7. 다른 형식으로 저장·열기 (TXT·PDF)

파일 메뉴에서 문서를 텍스트(TXT)로 저장하거나, 텍스트·PDF 파일을 불러올 수 있습니다.

  • 텍스트로 저장 (TXT) — 문서를 글자만 남긴 평문으로 내려받습니다. 표는 상자 글자(┌─┬┐│├┼┤└┴┘)로 그려서 메모장·터미널에서도 표 모양 그대로 읽히고, 가로·세로로 병합한 칸도 선이 정확히 그려집니다(한글은 두 칸 폭으로 계산해 줄이 맞습니다). 제목은 밑줄(═, ─), 목록은 글머리표, 그림·영상·도형은 [그림]/[영상]/[도형]으로 표시됩니다. 쪽 나누기는 폼피드 문자로 남아, 그 TXT를 다시 열면 쪽 나누기로 복원됩니다.
  • 텍스트·PDF 열기 — 내 PC에서 열기(업로드)로 .txt·.pdf도 엽니다. TXT는 인코딩(UTF-8/CP949)을 자동으로 판별해 문단으로 불러옵니다. PDF는 두 가지 방식 중 고릅니다 — 그대로: 쪽을 그림으로 렌더해 원본 그대로 보입니다(편집은 안 되지만 표·그림·서식이 흐트러지지 않음). 글자만: 글자를 뽑아 문단으로 넣습니다(편집 가능하지만 원래 배치는 사라짐). 스캔본처럼 글자가 없는 PDF는 "글자만"이 안내와 함께 거절되니 "그대로"로 여세요.
  • 인쇄 범위·진행 표시 (기기(RG DS)판 한정) — 인쇄를 누르면 문서 전체·현재 쪽·지정 범위와 부수를 고르는 창이 뜨고, 인쇄 중에는 진행 상태창에서 인쇄 취소를 할 수 있습니다. 공개 웹판에는 인쇄 기능이 없으니, 웹 버전은 브라우저 인쇄 기능을 사용하세요.
